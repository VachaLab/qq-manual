# Installing on Sokar

To install qq on the Sokar cluster (managed by NCBR), log in to `sokar.ncbr.muni.cz` and run:

```bash
curl -fsSL https://github.com/VachaLab/qq/releases/latest/download/qq-sokar-install.sh | bash
```

This installs qq into the home directory shared by all nodes of the cluster. Open a new terminal to start using qq.

***

For more details about the Sokar cluster, see [Sokar cluster specifics](../specifics/metacentrum_family.md).
