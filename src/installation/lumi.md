# Installing on LUMI

To install qq on the LUMI supercomputer, log in to `lumi.csc.fi` and run:

```bash
curl -fsSL https://github.com/VachaLab/qq/releases/latest/download/qq-lumi-install.sh | bash
```

This installs qq into the home directory shared by all nodes of the cluster. Open a new terminal to start using qq.

***

For more details about LUMI, see [LUMI specifics](../specifics/lumi.md).
